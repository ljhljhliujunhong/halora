# Halora

自己的 [Grok Build](https://x.ai) 桌面界面。打开它，选一个项目，就能直接跟 Grok 说话，不用盯着命令行。

中文名：星环。

## 需要什么

电脑里已经装好并登录过 Grok Build。Halora 调用的就是这份 Grok，能力没有另外阉过。

## 怎么跑

```bash
npm install
npm start
```

打包成 Windows 应用：

```bash
npm run pack
```

完成后，项目目录里的 `星环.exe` 就是最新版。双击它，或运行 `打开星环.bat`。

## 怎么用

1. 选一个项目文件夹。
2. 在下面的输入框里打字，回车发送。
3. 它要改文件或跑命令时，会先问你。
4. 左边按项目看对话，也可以同时开着几个窗口跑。

## 0.2 工作区功能

- 并行会话的权限请求分别排队，可以选择会话处理；停止任务会清理对应请求。
- 草稿、图片附件和待发队列会保存到本地。退出时提示正在运行的任务；重启后可查看中断任务并准备继续，待发队列需主动恢复发送。
- 额度查询失败时显示上次结果、更新时间和缓存标记；没有历史结果时显示暂不可用，并在后台重试。
- 侧栏新增改动审查、检查点、导出备份和设置。
- 改动审查支持文件差异、暂存、取消暂存以及提交已暂存文件。需要 Git 仓库根目录。
- 设置包含默认模型、权限模式、压缩阈值、发送快捷键、默认项目、主题、字号和恢复选项。
- 文件检查点支持自动或手动建立、恢复预览，以及恢复前自动备份。包含 Git 跟踪的文件和未忽略的新文件，上限 10,000 个文件、64 MB；忽略文件和嵌套仓库不在范围内。恢复不会改变暂存区。
- 对话回退使用 Grok 提供的回退点，执行前保存原始会话副本，并明确使用仅回退对话模式。旧版 Grok 不支持接口时会显示错误。
- 当前对话可导出 Markdown、JSON、HTML。附件记录保留路径，导出文件不内嵌附件。
- `.halora` 备份包含本机 Grok 会话、用户技能、Halora 设置、草稿、附件和文件检查点，不包含登录凭据。上限 256 MB、30,000 个文件。恢复前会备份现有数据，同路径覆盖、其它数据保留，随后重启应用。跨机器使用时需重新选择本地项目路径。

运行 `npm test` 验证恢复、权限队列、额度降级、文件审查和备份流程；运行 `npm run build:ui` 构建界面。

## 产品说明
